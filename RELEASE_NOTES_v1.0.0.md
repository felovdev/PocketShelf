# PocketShelf v1.0.0

First public MVP release.

## Included
- Save links, snippets, addresses, commands, and notes with titles and tags.
- Search saved items.
- Receive shared text from other Android apps.
- Share a saved item with a tap.
- Delete a saved item with a long press.
- Store entries locally in SQLite, without an account or internet permission.

## Known limitations
- No backup, import, or export yet.
- No encrypted storage.
- Uninstalling the app removes its local database.
- This is a debug APK build, not a signed production release.

## Build
The Android APK is built by the GitHub Actions workflow. Open the latest successful **Android APK** run and download the `PocketShelf-debug-apk` artifact.
